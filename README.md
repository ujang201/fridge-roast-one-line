# Fridge Roast: One Line, Biggest Laugh

One original line of plain text roasting a smart fridge: it pushes a firmware update at 3 a.m. and afterwards the ice maker needs a subscription — it used to just be cold. The angle is fresh (firmware + subscription lock on a basic job), specific to smart fridges, and avoids the obvious cracks about ordering groceries or watching you.

## The entry

> My smart fridge pushed a firmware update at 3 a.m. and now the ice maker needs a subscription — it used to just be cold.

## Run

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). The output is deterministic: every run writes the same bytes. The program also self-checks the gate itself — it refuses to write a line outside 1–200 characters or one that is only whitespace.
